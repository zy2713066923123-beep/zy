# 微信小程序脚本

本目录下主要放依赖 `WX_SERVER` 获取微信小程序 `code` 的签到与任务脚本。首次使用一般需要先在对应微信小程序内完成注册、授权或绑定手机号。

## ⚙️ 环境变量配置（极简单变量）

现在仅需配置 **1 个环境变量**：

| 环境变量 | 必填 | 说明 | 示例 |
|:---|:---:|:---|:---|
| **`WX_SERVER`** | **是** | `yyb_go` 服务地址 | `http://127.0.0.1:8000` |
| `WX_ID` | 否 | （可选白名单）默认无需配置，脚本会自动从 `yyb_go` 获取所有存活账号并按协议类型自适应运行。仅当只想跑特定账号时才填写。 | `openid1&openid2` |

> 兼容说明：仍向下兼容 `YYB_SERVER` / `WECHAT_SERVER` 历史环境变量。
